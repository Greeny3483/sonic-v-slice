# VS Sonic.EXE V-Slice Port

Relive **VS Sonic.EXE** on a new engine!  

---
Includes multiple iconic songs from everyone's favorite and original mod—**VS Sonic.EXE**!

This mod quickly rose to fame due to it near-perfectly capturing the essence of what is one of the most popular creepypasta stories ever! I thought there was no better reason for bringing it to the most modern version of the game.

This mod features *built-in ghost tapping*, as well as a *custom HUD*. Other **ghost tapping or interface mods may conflict**

---

### INSTALLATION INSTRUCTIONS:

- Drag and drop `sonic v-slice` into your base game **mods** folder
- If no mods folder exists, create one
- Extract the mod to minimalize issues. (Errors, characters not loading, etc.)
